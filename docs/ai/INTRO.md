## Project Summary

Server Toolkit is a modern Android application for Linux server administration and infrastructure management.

The project is treated as a production-quality software product, not as a tutorial or prototype.

The application focuses on operational workflows such as:

- Server inventory
- Dashboard
- SSH-based administration
- Monitoring
- Command execution
- Xray and x-ui management
- Certificate helper workflows

SSH is one feature of the product, not the entire product.
