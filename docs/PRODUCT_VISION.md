# Purpose

Server Toolkit is a modern Android application designed for Linux system administrators, DevOps engineers, infrastructure engineers, and advanced users who manage one or multiple remote servers.

The primary goal of this project is to simplify day-to-day infrastructure management from a mobile device.

Unlike traditional SSH clients, Server Toolkit focuses on operational workflows instead of providing only terminal access.

---

# Problem Statement

Most Android SSH applications provide only a terminal emulator.

Administrators still need multiple applications to perform common operational tasks such as:

- Managing server inventory
- Monitoring server availability
- Executing predefined maintenance commands
- Managing Xray and x-ui services
- Renewing certificates
- Viewing system status
- Organizing production and test environments

Server Toolkit aims to combine these tasks into a single modern application.

---

# Vision

Provide the best Android application for infrastructure management while keeping the interface clean, fast, secure, and easy to use.

The application should become the primary mobile companion for Linux server administration.

---

# Non-Goals

The project is not intended to replace:

- Desktop SSH clients
- Full monitoring platforms
- Configuration management systems
- Kubernetes dashboards

Server Toolkit complements existing infrastructure tools instead of replacing them.

---

# Success Criteria

The project will be considered successful when administrators can perform their most common daily maintenance tasks from their mobile device in less than one minute.
